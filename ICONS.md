# Icon art

Drop PNG files into `config\icons\` (next to the exe). Square, transparent background, 128-256 px, and readable at about 22 px. Missing files simply fall back to placeholders or text.

| File | Used for |
|---|---|
| `Profile_icon.png` | PROFILE window: minimized icon and title bar |
| `Visualizer_icon.png` | VISUALIZER window: minimized icon and title bar |
| `Keybinds_icon.png` | KEYBINDS window: minimized icon and title bar |
| `Service_icon.png` | SERVICE window: minimized icon and title bar |
| `Debugger_icon.png` | DEBUGGER window: minimized icon and title bar |
| `Theme_icon.png` | THEME window: minimized icon and title bar |
| `Settings_icon.png` | SETTINGS window (minimized icon and title bar) and the top-right settings button |
| `Github_icon.png`, `Youtube_icon.png`, `Tiktok_icon.png`, `Discord_icon.png` | Optional: replace the social text links |

Other art: `espdevice.ico` (app and tray icon) and the logo (THEME window) already exist.
